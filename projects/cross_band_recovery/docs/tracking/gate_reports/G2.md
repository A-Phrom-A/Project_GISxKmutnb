## 3. นวัตกรรมทางวิศวกรรมที่นำมาใช้ใน Phase 2

1. **WGS84 Unified Geographic Block Partitioning (5×5 กม.):**
   ระบบกำหนดกริดเชิงพื้นที่คงที่ $0.045^\circ \times 0.045^\circ$ ($\approx 5.0 \times 5.0$ กม.) อ้างอิงจุดกึ่งกลางละติจูด/ลองจิจูดจริงของไทล์ ทำให้ภาพถ่ายจากคู่ภาพต่างวันหรือระบบพิกัดต่างระบบ (เช่น EPSG:4326 และ UTM 47N) ได้รับการจัดกลุ่มลงบล็อกภูมิศาสตร์เดียวกัน ป้องกันปัญหา Data Leakage ข้ามฉากได้อย่างเด็ดขาด
2. **Buffer Exclusion Zone:**
   บล็อก Train ทุกบล็อกที่อยู่ติดกับบล็อก Test ภายในระยะ 1 บล็อก ($\approx 5$ กม.) จะถูกตัดเป็น Buffer Block ทันที ทำให้ระยะห่างทางกายภาพจริงระหว่าง Train และ Test ทุกคู่ในระบบมีค่า $\ge 5,086.9$ เมตร (ห่างกว่า Buffer ขั้นต่ำ $1,280$ เมตรเกือบ 4 เท่า)
3. **Dynamic S1/S2 Dual-Resolution Resampling:**
   ในคู่ภาพ PAIR-RAW-006 ซึ่ง S1 มีความละเอียด $20$ ม. และ S2 มีความละเอียด $10$ ม. ระบบคำนวณอัตราส่วนมาตราส่วนหน้าต่าง และทำ Bilinear Resampling บนข้อมูล S1 แบบ on-the-fly เข้าสู่กริด $10$ ม. ของ S2 ทำให้เกิดการทับซ้อนเชิงเรขาคณิตที่สมบูรณ์
4. **Single-Pass Memory Caching with Fast `.npz` Archive:**
   สถาปัตยกรรมไปป์ไลน์แบบ Single-Pass ทำการคำนวณ Lee Filter, บันทึกสถิติ Train และจัดเก็บไทล์ $1,562$ ลูกแบบ Uncompressed ZIP Archive เสร็จสิ้นในเวลาเพียง $44.3$ วินาที พร้อมเพิ่มความเร็วในการอ่านของ PyTorch DataLoader ในขั้นตอนการเทรนมากกว่า 10 เท่า
