## 2. ตารางผลการทดสอบเปรียบเทียบโมเดล Baseline บน Validation Split

ประเมินบนชุด Validation (80 ไทล์ตัวแทน, $1.31$ ล้านพิกเซลต่อเงื่อนไข) ครอบคลุม Representative Patterns สำหรับ $k \in [1..7]$:

| โมเดล Baseline | สถาปัตยกรรม | Input Features | MAE $\downarrow$ | RMSE $\downarrow$ | PSNR (dB) $\uparrow$ | SSIM $\uparrow$ | SAM (deg) $\downarrow$ |
|---|---|---|:---:|:---:|:---:|:---:|:---:|
| **B0: Mean-Fill** | ค่าเฉลี่ยคงที่จากชุด Train | None (Constant) | $0.0500$ | $0.0678$ | $23.80$ | $0.8722$ | $7.98^\circ$ |
| **B2: Pixel MLP** | 3-Layer MLP ($128$ dim, GELU) | Visible Opt + SAR + Mask Ind | $0.0488$ | $0.0658$ | $24.16$ | $0.8810$ | $7.95^\circ$ |
| **B1: Ridge Linear** | Linear Regression ($\alpha=1.0$) | Visible Opt + SAR + Mask Ind | $0.0349$ | $0.0477$ | $27.50$ | $0.9064$ | $6.00^\circ$ |
| **B3: Random Forest** | 30 Trees, max depth 10 | Visible Opt + SAR + Mask Ind | **$0.0322$** | **$0.0451$** | **$27.74$** | **$0.9031$** | **$5.53^\circ$** |

### ข้อค้นพบสำคัญ:
1. **B0 (Mean-fill) มีความคลาดเคลื่อนสูงสุด:** ให้ MAE $= 0.0500$ และค่าความคล้ายคลึงเชิงสเปกตรัมต่ำสุด (SAM $= 7.98^\circ$) ยืนยันว่าการเติมค่าคงที่ไม่สามารถตอบโจทย์การกู้คืนแบนด์
2. **Ridge Linear และ Random Forest มีความสามารถสูงในการจับความสัมพันธ์ระหว่างแบนด์:**
   - Random Forest ลด MAE ลงเหลือ $0.0322$ (ดีกว่า Mean-fill ถึง $35.6\%$) และลดมุมสเปกตรัมลงเหลือ $5.53^\circ$
   - ยืนยันว่าแบนด์ที่มองเห็น (เช่น Red, RedEdge, NIR) มีสหสัมพันธ์ภายในสูง (Inter-band cross-correlation) ซึ่งเป็นรากฐานสำคัญให้ ViT นำไปต่อยอดด้วยบริบทเชิงพื้นที่ (Spatial Context)
3. **การแยกชุดข้อมูลอย่างเด็ดขาด (CHK-G3.5):**
   - การฟิตโมเดล Baseline ทั้งหมดใช้พิกเซลสุ่มจาก `data/tiles/train/` เท่านั้น
   - การวัดผลรันบน `data/tiles/val/` เท่านั้น โดยชุด `data/tiles/test/` ถูกล็อกไว้ $100\%$ ไม่มีการเปิดใช้งานจนกว่าจะถึง Phase 8 (P8)
