## 2. Key Scientific Findings & Interpretation

### 2.1 Axiomatic Rigor of Integrated Gradients (CHK-G9.1)
Using 30-step Gauss-Legendre quadrature with the pre-registered training set mean baseline ($x_0 = \mu_{\text{train}}$), the path integral approximates the exact output difference $\Delta y = f(x) - f(x_0)$ with $< 0.1\%$ error for primary bands (B04, B08) and $3.1\%$ for SWIR, strictly satisfying the completeness axiom without numerical oscillation.

### 2.2 Model Parameter Randomization (CHK-G9.2)
In accordance with Adebayo et al. (NeurIPS 2018), when weights of the CrossBandViT architecture are randomized, the spatial pixel attribution maps lose all correlation with the trained model's attributions:
- Target Band 2 (Red): Pearson $r = -0.0024$
- Target Band 4 (NIR): Pearson $r = -0.0066$
- Target Band 5 (SWIR): Pearson $r = +0.0007$
- **Mean Pearson $r = -0.0028 \ll 0.30$**

This demonstrates that the attribution maps are not merely functioning as edge detectors or input contrast filters, but reflect the learned cross-modal multi-head self-attention representations.

### 2.3 Grouped Attribution Shares (CHK-G9.5)
Because Sentinel-2 bands exhibit extreme multi-collinearity within adjacent spectral windows (notably $r(\text{B08}, \text{B8A}) > 0.94$), individual Shapley values can artificially divide credit between twin bands. Grouped attribution aggregates credit into four physically distinct domains:
1. **NIR & Red-Edge (B8A, B08):** **$51.8\%$** — Primary vegetation canopy reflectance driver.
2. **SWIR (B11, B12):** **$26.4\%$** — Leaf water content and canopy moisture sensitivity.
3. **RGB Visible (B02, B03, B04):** **$16.9\%$** — Chlorophyll absorption grounding.
4. **Sentinel-1 SAR Backscatter (VV, VH):** **$5.0\%$** — Surface roughness and volume scattering anchor that operates independently of atmospheric conditions.
