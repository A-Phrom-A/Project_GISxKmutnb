ข้อควรทราบด้านระยะเวลาและคุณภาพการสกัดแปลง (SAM-1 Notice):

• ระยะเวลาในการทำงาน: การประมวลผลด้วยโมเดล Segment Anything (SAM-1) บนภาพถ่ายดาวเทียมขนาดใหญ่ ใช้ระยะเวลาในการทำงานนาน เนื่องจากต้องทำการสแกน Grid Point ทั่วทั้งภาพ
• คุณภาพของแปลง: ผลลัพธ์จากการ Segment ด้วยโมเดล SAM-1 ทั่วไปจะมี คุณภาพต่ำกว่าที่ควรเป็น เนื่องจาก SAM เป็น Generic Foundation Model ที่ไม่ได้ถูก Fine-tune เฉพาะทางสำหรับทรงพุ่มปาล์มน้ำมัน อาจเกิดขอบเขตแปลงแตกย่อยหรือซ้อนทับกัน
